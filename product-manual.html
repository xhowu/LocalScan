产品技术手册

码上记 LocalScan

一款注重隐私、无需账号与云端的本地物品 / 库存管理工具。扫码建档、状态跟踪、导出备份与多设备点对点同步，数据默认留在本机。

产品定位

面向需要清晰掌握物品归属与数量、同时不愿把数据交给第三方的个人与小团队。 产品以「本地存储」为默认状态，以「主动导出 / 同步」为可选扩展。

无账号 不强制联网 本机数据 点对点可选

典型场景

  • 个人数码 / 工具箱、家庭物资与药品
  • 小团队仓库盘点、工作室物料台账
  • 需要临期 / 过期提醒的耗材与食品

功能说明（与 v1.4.0 实现一致）

模块能力说明
物品管理 CRUD、数量、图片 新建/编辑/删除；数量 ± 与键盘直改；图片压缩、删除、排序
扫码 相机 + 相册 + 手动 Android 使用 Google ML Kit；Web 兜底 zxing + jsQR；闪光灯；结果弹窗
多仓库 切换与隔离 左缘滑出侧滑；状态与物品页四格卡片同步；导出绑定当前仓
分类 / 位置 可管理维度 新建、改名、排序、删除；列表筛选并记忆
日期保质 截止 / 临期 / 过期 生产日期 + 保质期（月）自动算截止；临期阈值驱动统计与筛选
状态体系 可配置卡片 在库/低库存/零库存/临期/过期等；可隐藏排序；首页四格可选
导出 表格与归档 CSV / XLSX / 含图 ZIP；综合导出为单份 ZIP；Android 写入 Documents/LocalScan
同步 / 备份 P2P 与加密 JSON 同步包字段合并；AES-GCM 加密 .enc；局域网只读 HTML 面板

说明：未实现「中国物品编码中心商品库查询」；扫码仅作本地物品标识绑定。

状态与数值规则

规则定义
截止日期 生产日期 + 保质期（月），按本地日历加月
在库 数量 > 0
低库存 0 < 数量 ≤ 低库存阈值
零库存 数量 = 0
临期 未过期，且 截止 − 今天 ≤ 临期阈值（月）
过期 截止日期 < 今天 − 1 日（一日宽限）
同步合并 按 id / 条码匹配；较新 updatedAt 覆盖字段；version + 1；不改动其它仓库

技术架构

  • 前端：React 19 + TypeScript + Vite
  • 壳层：Capacitor 8 · Android WebView
  • 扫码：Google ML Kit（原生相机 / 相册）；Web 兜底 zxing + jsQR
  • 存储：localStorage JSON（items / warehouses / meta / images）
  • 导出：SheetJS xlsx · JSZip · AES-GCM 加密备份

代码结构：约 5k 行源码；页面 UI 为主，其次数据层与壳层样式。App 内「关于」页含可交互饼图。

安装与使用

  • 安装 LocalScan-debug.apk（允许未知来源）
  • 首次进入会生成示例仓库与物品，可在设置中清空
  • 扫码需相机权限；无相机时可用相册识别或手动输入
  • 导出文件位于系统「文档 / LocalScan」
