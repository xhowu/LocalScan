码上记 LocalScan

本地物品与库存管理。扫码建档、状态跟踪、离线导出；数据默认留在设备里， 需要时再通过文件或点对点同步带走——不绑账号，不上云。

核心能力

01

物品台账

名称、条码、分类、位置、数量与财务信息；图片可删可排序；长按卡片快捷操作。

02

扫码建档

Android 上 Google ML Kit 相机 / 相册识别；Web 兜底 zxing + jsQR；闪光灯与结果弹窗。

03

多仓库

左缘滑出切换；首页状态卡片与仓库统计同步；导出与同步绑定当前仓库。

04

临期体系

生产日期 + 保质期（月）自动算截止；临期阈值驱动在库 / 临期 / 过期统计。

05

可配置筛选

分类 / 位置 / 状态多维筛选并记忆；状态卡片可排序、隐藏、恢复。

06

导出与同步

CSV / XLSX / 含图 ZIP；JSON 同步包合并；AES-GCM 加密备份与局域网面板。

典型场景

个人数码 / 工具箱 家庭物资与药品 耗材临期提醒 小团队仓库盘点 工作室物料台账

适合需要「一眼看清有多少、在哪里、是否临期」，又不愿把数据交给第三方的用户。

状态与计算规则

规则定义
截止日期生产日期 + 保质期（月），按本地日历加月
在库数量 > 0
低库存0 < 数量 ≤ 低库存阈值
零库存数量 = 0
临期未过期，且 截止 − 今天 ≤ 临期阈值（月）
过期截止日期 < 今天 − 1 日（一日宽限）
同步合并按 id / 条码匹配；较新 updatedAt 覆盖字段；version + 1
扫码只绑定「本地物品标识」，不做商品百科查询；未接入商品编码中心接口。

安装与开始

  • 下载 LocalScan-debug-v1.4.0.apk，允许未知来源后安装
  • 首次启动会写入示例仓库与物品，可在设置中一键清空
  • 导出文件写入系统「文档 / LocalScan」
  • 浏览器打开 设计方案页 可查看设计说明
