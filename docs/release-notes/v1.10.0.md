## 两个版本，可同时安装

| | 离线版（推荐） | 联网版 |
|---|---|---|
| 包名 | `com.localscan.app` | `com.localscan.app.online` |
| 联网代码 | **无**（联网查询在编译期被整体移除，不存在于安装包内） | 含条码商品信息查询，**默认关闭** |
| 同时安装 | ✓ 图标与数据各自独立 | ✓ |

除联网查询外，两个版本的功能完全相同。

**隐私边界**：联网版只在「条码商品信息查询」开关打开时，才把条码数字发送给所选数据源（GS1 → MXNZP → Open Food Facts 三级兜底）；其余任何数据都不出设备。离线版则不存在联网代码。

## 功能一览（15 个模块）

- **物品管理** — CRUD 与数量输入；长按快捷菜单；图片压缩 / 删除 / 排序；图片查看器（双指缩放 / 双击 / 切换）；名称跑马灯；旋转语义区分
- **扫码** — ML Kit 原生识别（EAN / UPC / Code128 / QR 等）；相机 / 相册 / 闪光灯 / 结果弹窗 / 手动输入；内嵌相机浮层；相机严格状态机；聚焦即关相机与键盘适配；结果弹窗轻微震动
- **日期与临期** — 生产日期 + 保质月 → 截止日期；临期阈值可按物品设置；输入即时校验（天数 / 闰年 / 超前提示）
- **状态筛选** — 在库 / 低库存 / 零库存 / 临期 / 过期 / 无日期 / 无条码；可排序 / 隐藏 / 恢复；首页四格卡片可配置
- **批次子项** — 同条码多批次，各自日期与数量；父项归组 · 详情互跳 · 重复提示；子项两层限制
- **联网查询**（联网版） — 扫码命中查询商品信息；三级兜底；手动输入同链路；默认关闭
- **文字识别** — 拍照 / 相册 ML Kit 中文 OCR；自动抽取名称 / 规格 / 净含量 / 日期
- **多仓库** — 抽屉切换（顶栏按钮，左缘滑出）；状态卡片与物品页同步；全仓导出按原仓库还原
- **分类与模板** — 临时字段与固定字段模板；位置字段与分类位置管理
- **导出** — CSV / XLSX 表格导出；含图 ZIP（表格 + 数据 + 图片打包）；范围开关（当前 / 全部仓库）；多仓库自动分工作表
- **同步备份** — JSON 同步包合并；AES-GCM 加密备份；导入前校验弹窗；换机全量迁移（图片本体随包）
- **局域网面板** — 只读 HTML 快照（多 sheet 页签）；搜索 / 自适应 / 表头吸顶；深浅色三态开关
- **回收站** — 软删除集中查看；恢复（父项连带子项）/ 彻底删除
- **手册** — 内置全功能说明 · 目录跳转；全文搜索荧光高亮；搜索控件悬浮化；回车跳第一处命中
- **显示与操作** — 深浅色主题；返回键 / 手势导航；字体大小四档；安全区适配；双击顶栏回顶；长按语义区分（控件不可选，内容可复制）；返回定位（下级返回保留位置与展开，同级切走则收回）

## 安装

1. 下载对应架构的 APK
2. 首次安装需在系统中允许「安装未知来源应用」
3. 离线版与联网版包名不同，可同时安装
4. 从 v1.4.0 升级：同包名覆盖安装即可保留历史数据，稳妥起见建议先在旧版导出 JSON 备份

## 关于体积

安装包 75 MB（universal）中，约 73 MB 是 Google ML Kit 的中文 OCR 与条码识别原生引擎（`libmlkit_google_ocr_pipeline.so` 39 MB + `libbarhopper_v3.so` 19 MB + 绑定层），以及为兼容各 CPU 架构的多份副本。自写前端产物仅约 1.8 MB。这是「不依赖 Google Play 服务、任何国内机型装上即可离线扫码与识别文字」的代价。
