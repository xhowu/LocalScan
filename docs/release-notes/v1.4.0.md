## 包含内容

- **物品台账** — 名称、条码、分类、位置、数量与财务信息；图片压缩 / 删除 / 排序；长按卡片快捷菜单
- **扫码建档** — Android 上 Google ML Kit 相机 / 相册识别；相机取景框 + 闪光灯开关；结果弹窗展示同码物品；手动输入条码查询
- **多仓库** — 数据按仓库隔离，左缘滑出抽屉切换；状态卡片与物品页四格统计同步
- **分类位置** — 分类与位置完全自定义，可新建、改名、排序、删除；列表筛选并记忆选择
- **临期体系** — 生产日期 + 保质期（月）自动算截止日期；临期阈值驱动在库 / 临期 / 过期统计；按本地日历加月
- **状态筛选** — 在库 / 低库存 / 零库存 / 临期 / 过期 / 无日期 / 有条码 / 无条码 / 近 1 天 / 近 1 周 / 近 1 月新增；状态可排序、隐藏、恢复
- **导出** — CSV / XLSX / 含图 ZIP；综合导出单份 ZIP；保存到 `Documents/LocalScan`
- **同步备份** — JSON 同步包合并（id / 条码匹配，较新者胜）；AES-GCM 加密备份（`.enc`）；局域网只读 Web 面板快照
