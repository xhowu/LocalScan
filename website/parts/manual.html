码上记『LocalScan』App 使用手册

适用版本：v1.10.0（离线版 / 联网版）。

本文所有功能描述均与当前代码实现逐条核对，没有的功能不会出现在本文中，有的功能也不会遗漏。

1. 认识码上记

码上记（LocalScan）是一款隐私优先的本地物品 / 库存管理应用，定位于"给自己的东西记一本账"：家里的杂物、仓库的货、工作室的器材，都可以用它登记、查找、盘点和导出。

它的三条基本原则：

  • 无账号：不注册、不登录，没有任何用户体系。
  • 无云端：所有数据（物品、仓库、图片）都保存在你手机本地的浏览器存储（localStorage）里，应用不内置任何上传通道。
  • 可带走：任意时刻都可以把全部数据导出为表格、备份包或加密备份，换机不依赖任何"云同步"。

应用由 React 19 + TypeScript 编写界面，通过 Capacitor 8 打包为 Android 应用；扫码与文字识别使用 Google ML Kit 原生能力，浏览器预览环境下降级为 zxing + jsQR 纯前端识别。

本手册内置在 App 中（关于页 → 手册）：目录点击跳转，有子项的章节可展开小节并跳转，右下角浮球可随时呼出目录（目录条加高便于点选）；搜索按关键词全文匹配，所有命中处荧光笔高亮且不隐藏任何内容，顶栏正下方固定高度的红色上下箭头控件可逐处跳转（N/M 计数，当前处橙色高亮）；输入后按回车立刻前往第一处命中并收起键盘。关于页的「功能」列表与本手册逐条对应：点击模块展开子功能后，按子功能条或模块右侧的「说明」可直接跳转到本手册的对应章节。

2. 安装与双版本

码上记提供两个可共存的安装包：

版本包名联网能力
离线版com.localscan.app无任何联网代码（联网查询在编译期被整体移除，不存在于安装包内）
联网版com.localscan.app.online可开启"条码商品信息查询"（见第 9 章），其余与离线版完全一致

两个版本可以同时安装在同一部手机上，图标独立、数据各自独立。除联网查询外的一切功能在两个版本中完全相同。

3. 快速上手

首次启动时应用会自动创建第一个仓库「我的仓库」，并写入少量示例物品（含一条 Type-C 数据线、便携风扇、收纳箱，以及同一数据线下的第二个批次子项），用于直观展示"父子批次"的组织方式。示例数据可以随时修改或删除，也可以在设置中「清空全部数据」恢复示例。

最短路径上手流程：

  1. 在物品页点击右下角红色加号（FAB）新建物品，或在扫码页扫描商品条码直接建档。
  2. 用顶栏的「仓库」按钮切换 / 新建仓库，数据按仓库隔离。
  3. 需要备份时进入 设置 → 导出与同步，选择表格导出、同步包或加密备份。

三个核心概念先建立起来，后面所有功能都围绕它们展开：

  • 仓库（Warehouse）：数据的第一级隔离单位，每个仓库有独立的物品集合与统计。
  • 物品（Item）：登记的主体，包含条码、名称、分类、位置、数量、价格、日期、自定义字段与图片。
  • 批次（父子关系）：同一仓库内条码相同的物品会组织成"父项 + 子项"两层结构，用来表达"同一商品的不同批次"。

4. 界面导览

  • 顶栏（固定，不随内容滚动）：左侧是 LOCALSCAN / 码上记品牌标识，右侧是「仓库」切换按钮，显示当前仓库名，点开仓库抽屉。
  • 底部页签：主导航，包含物品、扫码等一级页面；编辑、关于等二级页面不显示页签。
  • 悬浮加号（FAB）：仅物品页出现，固定在右下角，点击直接新建物品。它悬浮在内容层之外，列表滚动与回弹不会带动它。
  • 页面进入动效：页面切换有轻微上移入场动效（扫码页除外，避免相机取景框测量偏移）。
  • 安全区适配：顶栏、底栏与抽屉按系统安全区（状态栏 / 导航条 / 刘海）自动让位，内容不被遮挡。

5. 物品管理

5.1 物品列表

物品页从上到下依次是：

  • 搜索框：按名称、条码、备注实时模糊搜索。
  • 状态统计卡：一行四格（可自定义显示哪些状态，见第 12 章），点击状态卡即按该状态筛选，再点取消。
  • 筛选栏：左侧显示"当前"筛选摘要（分类 / 位置 / 状态组合与命中数量），右侧漏斗按钮展开筛选抽屉，可按分类、位置、状态三者组合筛选，支持一键重置。
  • 物品卡片列表：按"父项 → 其子项"归组展示。父项卡片显示名称（过长自动滚动跑马灯，也可手动拖动查看）、条码、分类胶囊（按分类着色）、数量、单位、低库存 / 临期 / 过期等警示胶囊；有子项的父项可展开 / 收起，子项行显示各自的批次日期摘要与数量。

卡片交互：

  • 单击卡片进入物品详情。
  • 长按卡片弹出快捷菜单（编辑 / 删除）；滚动列表或点击别处会自动关闭菜单，长按抬指产生的误触点击不会立即关掉菜单。

5.2 新建与编辑物品

编辑页字段一览（全部与实现一一对应）：

字段说明
条码可由扫码 / 相册识别 / 手动输入填入；类型自动识别为 EAN13 / EAN8 / UPC / CODE128 / QR / CODE39 / 其他
名称必填主体，过长在列表中自动滚动展示
分类下拉选择，默认 8 类：数码、工具、家居、服饰、耗材、办公、食品、其他
位置存放位置（如 A架-03），可自由输入，值来源由"分类与位置"管理
数量与单位数量支持加减按钮与键盘输入；单位默认「件」
购入价 / 售价可留空；币种默认 CNY
低库存阈值默认 2；数量 ≤ 阈值且 > 0 时标记"低库存"
生产日期支持 20260911 或 2026-09-11 两种输入格式
保质期（月）填写后自动推算截止日期
截止日期由生产日期 + 保质期自动推算，编辑页没有单独的输入框（文字识别读到截止日期时会直接写入）。
临期阈值（月）默认 1；距截止日期不足 N 个月标记"临期"
备注自由文本
自定义字段由字段模板驱动的额外字段（见下），值保存在物品上
图片拍照或相册选择，自动压缩，可删除与排序

自定义字段模板（设置 → 自定义字段模板）：你可以预定义一组固定字段（如"保修到期""供应商"），编辑物品时这些字段会自动出现，所有物品共用同一套模板。字段值直接写在物品记录上，模板只负责"编辑页显示哪些字段"。

保存 / 取消采用 replace 导航，返回不会回退到编辑页。

5.3 物品详情

  • 状态胶囊行（数量区上方）：与物品页统计卡同一套判定规则，实时显示在库 / 低库存 / 零库存 / 临期 / 过期 / 无日期 / 无条码。
  • 标题自动滚动：名称超出导航栏宽度时自动往返滚动，可手动拖动。
  • 批次导航：子项详情页顶部显示"同条码父项"链接可跳回父项；"子项批次"框只在父项详情页显示（子项不能挂子项，框里空列表只会造成困惑）。
  • 图片点击进入全屏查看器：双指缩放、双击放大、左右切换多图、下拉关闭；支持 90° 旋转预览（退出不改变存储方向）。
  • 同条码的父项 / 子项可互相跳转（详情页内显示批次列表，点击即跳）。
  • 支持编辑、删除。删除物品为软删除（数据标记 deleted 保留在本地，界面不再显示），删除父项会级联软删其子项。

5.4 编辑页的更多细节

  • 条码填充来源：扫码页命中后的结果弹窗可以直接"新建物品并填入"，条码与联网查询到的商品信息（名称、品牌、规格、净含量等）一并带过来，缺省字段再手动补全。
  • 临时字段：识别文字自动抽取但无法归类的信息会以 tmp- 前缀的临时字段挂在新物品上，键名和值都可以修改，确认有用后保留即可。
  • 同批次查重：对同一条码新建批次时，若生产日期与到期日期都和已有批次相同，应用会提示疑似重复，避免重复登记。
  • 父项的批次提示框："该项下有 N 个子项批次"提示框在浅色模式下的边框已加清晰（此前几乎看不出是个框）。
  • 数量输入：数量支持加减步进与直接键入；负数与非法输入会被拒绝。
  • 日期即时校验（输入框下方当场提示，红字为问题、绿字为有效回显）：
  • 年份支持 4 位 0000–9999；月份 01–12；天数按当月真实天数限制（含闰年规则）；
  • 位数不足：提示"还差 N 位，凑满 8 位自动推算截止日期"；
  • 月份数字不存在（如 20261301 的 13 月）：提示"生产日期无效，13月月份不存在，不参与保存"；
  • 天数不存在（如 20261232 的 32 日）：提示"生产日期无效，32日天数不存在，不参与保存"；
  • 月、日都不存在（如 20261332）：提示"生产日期无效，13月32日日期不存在，不参与保存"；
  • 非闰年写 2 月 29 日：提示"生产日期无效，非闰年02月无29日，不参与保存"；其他月份天数超出（如 4 月 31 日）：提示"生产日期无效，04月无31日，不参与保存"；
  • 日期合法但晚于今天：红字提示与今天的间隔（换算为年月日，不足补零）——如今天是 2026年9月24 日、输入 20260930，提示"晚于今天，超前生产0000年00月06日，请核对"（警示不阻止）；
  • 日期合法且不晚于今天：绿字回显推算的截止日期（如"截止日期 2028年3月1日"；未填保质期则回显生产日期有效）。

5.5 回收站

入口：设置 → 数据 → 回收站。软删除的物品会保留在本地存储里（这就是"数据还存在"的含义——记录标了 deleted 标记、界面不再显示，但一直占着存储），回收站把它们全部列出：

  • 每条显示名称、所属仓库、数量与删除时间。
  • 恢复：一键回到原仓库；恢复的是父项时，其下已删除的子项批次会一起恢复。
  • 彻底删除：把记录从存储中真正移除，其独占的图片数据一并清理；此操作不可恢复。
  • 清空回收站：一键彻底删除全部软删物品。

6. 批次与父子关系

这是码上记处理"同一商品多批次"的核心机制：

  • 两层结构：同一仓库内条码相同的物品自动归为一组——最早登记的是父项，之后同条码新建的是子项（批次）。子项不允许再挂子项：如果导入数据里出现指向子项的父子关系，应用会自动上溯到根父项；上溯不到就成为独立物品，绝不会出现"孙项"。
  • 新建批次：在扫码结果或详情页对已有条码选择"新建批次"，记录各自的生产日期与数量。
  • 重复提示：同条码下生产日期与到期日期完全相同的批次会被识别为疑似重复并提示。
  • 批次排序：子项按"生产日期 → 到期日期 → 创建时间"排序，列表按父项在前、子项紧随其后展示。
  • 日期摘要：每个子项显示批次标签，优先显示"生产 2026年3月1日"这样的生产日期，没有则显示到期日期，再没有显示"未填日期"。

7. 图片

  • 压缩：拍照 / 相册选图后自动压缩——最长边缩到 1080px 以内，JPEG 质量从 0.85 起步逐级下调，直到不超过 500KB。
  • 存储：图片以压缩后的 data URL 直接存入本地存储，与物品记录同生共死。
  • 编辑：编辑页支持旋转（旋转结果写回原图，不留孤儿数据）、删除、排序（多图时决定展示顺序）。
  • 详情页旋转仅为预览方向，不改动存储。

8. 扫码与识别

扫码页顶部有模式开关：扫描条码 ↔ 识别文字，两者共用一页、切换即换工作方式。

8.1 扫描条码

  • 内嵌相机：进入扫码页页相机即自动就位——原生相机预览层精确嵌在页面取景框内（带 22dp 圆角裁切），取景框带四角红角标与往返扫描线；手电筒按钮在取景框内右上角，可在画面里直接开关闪光灯。页面其余部分照常显示与滚动；滚动页面时相机自动让位、停稳后归位。
  • 相机开关（严格两条件，无判定容差）：开启的唯一情况是页面在顶部且没有任何滑动（顶部判定 scrollTop=0，无容差）；页面离开顶部存在任意滑动——滚动、拖拽、顶部回弹——相机立即关闭，停止滑动回到顶部后自动恢复。仓库抽屉、结果弹窗等全屏遮挡出现时同样撤下，关闭后按同一规则恢复；点击手动输入框也会立即撤下相机（输入态无需取景）。顶部轻微触摸（拖拽位移 ≤12px 且未发生真实滚动）不会触发相机的开与关——避免填满屏幕的页面被“无感滑动”误关。相机关闭时取景框显示扫描图标与"上滑或点击扫描识别 / 对准条形码或二维码"（与识别文字界面同款样式），点击它页面自动回到顶部并开启相机——这是开启相机的唯一入口。相机启动失败不会崩溃，一律以提示形式反馈。
  • 让位的完整场景清单：①打开仓库抽屉；②扫码结果弹窗弹出；③页面发生真实滚动（内容超出屏幕时）。三者都会撤下相机；对应恢复时机分别是抽屉关闭、弹窗关闭、滚动停稳。内容不满一屏时滑动页面不会触发相机的开关。
  • 权限：首次使用会请求系统相机权限；拒绝后页面会提示到系统设置开启，不会反复弹窗。
  • 取景框内 UI 属于原生层：手电筒按钮与"对准条码即可识别"提示胶囊由原生相机浮层自己绘制（取景框区域被原生层覆盖，网页层画了也看不见），点击手电筒由原生直接切换闪光灯，不经网页中转。
  • 识别范围：EAN-13 / EAN-8 / UPC-A / UPC-E / Code128 / Code39 / Code93 / ITF / Codabar / QR / DataMatrix。
  • 命中流程：识别成功后相机撤下，弹出结果弹窗：显示条码内容与格式、本仓库已有的同条码物品（列出前 4 条，更多折叠）、联网查询结果（仅联网版，见第 9 章），并可一键"新建物品并填入"。结果弹窗出现时会有一次轻微震动反馈。
  • 结果弹窗：遮罩为全屏覆盖（含状态栏与导航条区域），视觉无割裂；查询结果不会被同码的重复上报冲掉（同码 5 秒内只认一次命中）。
  • 相册识别：不开相机也能从相册选图识别条码。
  • 手动输入：页面下方有手动输入框，直接键入条码查询，查询链路与扫码一致（联网版同样走三级兜底）。每次点击输入框都会立即撤下相机，并在键盘弹出动画的两个时点（约 0.35s / 0.7s）把输入框滚入可视区；若某些机型的 resize 被吞掉，应用会自动补一块与键盘等高的滚动空间并滚到底部——任意机型每次点击都抬升；收起键盘自动回到顶部并恢复相机。
  • 对同一张画面原生层做了节流（约 1.2 秒内不重复上报同一批命中），避免连续弹窗。

8.2 识别文字

  • 两种入口：页面中央大按钮直接调起相机拍照，或从相册选图。
  • 识别引擎：原生 ML Kit 文字识别，指定中文模型。
  • 字段抽取：识别出的文本会按行解析，自动抽取名称、规格、净含量、保质期、生产日期等常见标签值，核心参数（名称、规格、数量、日期等）直接填入新建表单，无法归类的内容进入"临时字段"，可自行改 Key 保留或删除。

9. 联网查询（仅联网版）

默认关闭，保证隐私；开启后扫码命中会自动联网查询商品信息并在结果弹窗展示，可一键填入新物品。

  • 数据源一：默认库（GS1 - MXNZP - OFF）。设置页显示为"默认库"，内部按三级自动换源：先查 GS1 注册库（经第三方聚合接口转发中国物品编码中心注册数据，匿名有极小试用额度），失败自动转 MXNZP 商品条码库（免费档每秒 1 次、限频自动重试一次），仍无结果再查开源库 Open Food Facts；成功结果显示实际来源。填写自己的 GS1 API Key 可提升第一级额度。
  • 自动兜底（三级）：GS1 渠道失败（网络错误、额度用完、返回错误码）或无结果时，自动转查 MXNZP 商品条码库（国内商品覆盖好），仍无结果再查开源商品库 Open Food Facts（匿名免费），查询结果会标注实际来源。
  • 数据源二：自定义接口。填入包含 {code} 占位符的 URL 与可选请求头，适配任何自建 / 自购服务。
  • 超时：默认 8000 毫秒，可调（下限 2000 毫秒）。
  • 隐私边界：查询时只会把条码数字发送给所选服务；返回数据仅用于填充物品信息，应用不做任何留存与上报。离线版在编译期就不含此功能。

10. 多仓库

  • 切换：点击顶栏「仓库」按钮，仓库列表会自屏幕左缘滑出（触发方式只有这一处，设置页的"当前仓库"也会打开同一抽屉）；抽屉内列出全部仓库（当前仓库置顶），每张卡片显示名称与种类数；名称过长时自动往返滚动、可手动拖动查看；卡片支持长按菜单（编辑 / 删除）。
  • 新建 / 编辑：仓库名称 + 备注。
  • 删除仓库：会同时删除仓库内的全部物品（这是硬删除，注意先导出备份），随后自动切换到剩余的第一个仓库；没有仓库时应用会引导创建。
  • 统计联动：仓库抽屉里的种类数、物品页四格状态卡，均实时反映当前仓库数据。
  • 首次使用若未选择仓库，应用会强制先打开仓库抽屉完成创建 / 选择。

11. 分类与位置

  • 默认分类：数码、工具、家居、服饰、耗材、办公、食品、其他，共 8 类。
  • 管理页（设置 → 物品参数 → 分类与位置）：可新建、改名、排序、删除分类与位置；删除时若仍有物品在使用，应用会给出相应处理提示。
  • 列表联动：物品筛选弹层中的分类 / 位置选项即来自这里；物品卡片上的分类胶囊按分类着色（每个分类有固定配色，深浅主题各自适配）。

12. 状态与筛选

状态是物品的派生标签，全部由字段实时计算，不占存储：

状态判定规则色调
在库数量 > 0中性
低库存0 < 数量 ≤ 低库存阈值琥珀警示
零库存数量 = 0红色危险
临期未过期，且距截止日期 ≤ 临期阈值（月）琥珀警示
过期截止日期早于昨天（含 1 天宽限）红色危险
无日期未填截止日期琥珀警示
无条码没有条码琥珀警示
有子项 / 无子项名下是否存在批次子项中性

状态筛选页（设置 → 状态筛选）：控制物品页显示哪些状态、以及排列顺序；物品页顶部的四格统计卡也从这里启用 / 停用的状态中选择。低库存、临期、无日期、无条码等警示状态在卡片与胶囊上使用琥珀色，零库存与过期使用浅红底红字，全 app 统一。

13. 日期与临期计算

  • 输入格式：20260911 或 2026-09-11，其他格式一律拒绝。
  • 截止日期 = 生产日期 + 保质期月数（按"本地日历加月"计算，1 月 31 日 + 1 个月 = 2 月 28 日，不会跳到 3 月）。
  • 过期：截止日期早于昨天（留 1 天宽限，当天到期不算过期）。
  • 临期：未过期，且截止日期距今 ≤ 临期阈值（月），每个物品可单独设置阈值，默认 1 个月。
  • 日期解析统一在"本地正午"锚定，避免时区差异导致跨天误判。

14. 导出与同步

入口：设置 → 导出与同步。支持选择导出范围：当前仓库 或 全部仓库；「包含图片」开关决定是否把图片本体打包进同步包 / 加密备份。

表格列（CSV / XLSX / 面板通用）：层级、所属父项、条码、名称、分类、数量、单位、购入价、售价、币种、备注、低库存阈值、入库时间、更新时间、版本。行按"父项在前、子项紧随（└ 标记）"排列。

14.1 表格导出

  • CSV：单文件，UTF-8。
  • 表格区三个导出按钮：.CSV、.XLSX、图片.ZIP（XLSX 表格 + inventory.json + images/ 图片文件夹）。
  • Excel（XLSX）：多仓库时自动分工作表——第一张「全部」总表，其后每个仓库一张（仓库名作表名，非法字符自动清理）。

14.2 含图 ZIP

把 XLSX 表格、inventory.json 原始数据和 images/ 图片文件夹打包成一个 ZIP，适合归档。

14.3 同步包（JSON）

.json 文件（schema 4），包含物品、仓库表（全仓导出时）与可选的图片本体。这是两台手机之间点对点同步的标准格式，合并规则见 14.5。

14.4 加密备份（.enc）

  • 算法：PBKDF2（120000 次 SHA-256）从口令派生密钥，AES-256-GCM 加密，随机盐与 IV，文件头带校验魔数。
  • 包内含物品、仓库表与图片本体——口令 + 一个 .enc 文件即可完成换机。
  • 导入时需要输入相同口令解密，应用会展示校验信息（数据类型、仓库与物品数量、导入目标），多仓数据导入单仓时会给出范围不一致的警示。

14.5 同步合并规则（两台手机点对点对账）

  • 合并只作用于目标仓库（默认当前仓库），绝不波及其他仓库的物品。
  • 按 id 匹配：本地不存在则新建；若该 id 已属于其他仓库，则分配新 id，不抢占。
  • 条码匹配仅作为兜底：只有当该条码在本仓库唯一命中且是父项时才视为同一物品（子项批次绝不参与条码匹配，防止批次被合并进父项）。
  • 双方都存在的物品：updatedAt 较新的一方胜出，逐字段覆盖并记录冲突清单（物品名、字段、双方旧值）供导入后查看；版本号取双方较大值 +1。
  • 图片取并集；子项导入后会自动回连到在本仓库中的父项。

14.6 文件名与保存位置

  • 单仓导出：仓库名 + 日期；全部仓库导出：机型名 + 日期 + 多仓（机型从系统信息读取）。
  • Android 上文件保存到 Documents/LocalScan，保存成功后 Toast 显示完整路径。

14.7 合并结果与冲突清单

每次导入同步包 / 加密备份后，应用会给出合并统计：新建多少条、更新多少条、跳过多少条，以及一份逐字段的冲突清单（物品名、字段名、本地旧值、远端新值）。冲突的处理规则是"较新者胜"：更新时间更晚的一方覆盖字段，但整条记录的版本号只增不减，图片永远取双方并集——可以放心反复互导对账。

15. 局域网 Web 面板

设置 → 数据 → 局域网 Web 面板，会把全部数据生成一个只读 HTML 快照文件（保存到本机，可随手通过局域网共享 / 网盘传到电脑浏览器打开）：

  • 与 Excel 相同的多工作表形式：第一张「全部」总表 + 每仓库一张页签。
  • 顶部搜索框：按名称、条码、分类、备注实时过滤当前表。
  • 深浅色三态开关（页头按钮）：跟随系统 → 深色 → 浅色循环切换，选择记忆在浏览器里。
  • 手机与电脑屏幕均已适配；表头吸顶、宽表横向滚动。
  • 页面是纯静态快照——生成后数据不再变化，重新生成即可刷新。
  • 离线版与联网版各自生成独立的面板文件（localscan-webpanel.html / localscan-webpanel-online.html），互不覆盖。
  • 面板自带层级列（父项 → └ 子项），与 Excel 导出的父子排布一致，适合直接投屏盘点。
  • 面板文件不包含任何脚本依赖与外部资源，单文件离线可用，也不会"回传"任何数据。

16. 设置

  • 外观：主题（浅色 / 深色 / 跟随系统）；字体大小（小 / 标准 / 大 / 特大），全局同比缩放。
  • 仓库：当前仓库入口（打开仓库抽屉）。
  • 物品参数：分类与位置管理、状态筛选管理、自定义字段模板管理。
  • 联网查询（仅联网版显示）：总开关、数据源、API Key / 自定义接口配置、超时；详细行为见第 9 章。
  • 数据：导出与同步入口、回收站（查看 / 恢复 / 彻底删除已删物品）、局域网 Web 面板生成。
  • 危险操作 → 清空全部数据：删除所有仓库与物品并恢复示例数据。为防误触需要连续通过两道确认弹窗（第二道会明确提示仓库数与不可撤销性）。清空后数据无法找回，请先导出。
  • 关于：版本（点击进版本日志）、关于 App（代码结构占比、功能模块清单——可展开子功能并点击直达手册对应章节、技术栈、日期计算规则说明）。

17. 数据存储与隐私

  • 全部业务数据存放在 WebView 的 localStorage（物品、仓库、图片 dataURL、主题、筛选配置、查询配置等），应用启动时载入内存、写入时统一落盘。
  • 没有任何账号系统、云服务、统计 SDK 或第三方数据上报；唯一可能的联网行为是联网版中你主动开启的条码查询。
  • localStorage 的容量上限（通常约 5–10MB，因设备而异）由系统决定；图片经过 1080px / ≤500KB 压缩，日常几百件物品含图使用是安全的。数据量大后建议定期导出含图 ZIP 归档。
  • 应用内置示例数据与 v1 旧版数据自动迁移逻辑；升级版本不会丢数据。

18. 导航与手势

  • 系统返回键 / 侧滑返回手势：优先关闭仓库抽屉等浮层 → 二级页回退到来源页 → 一级页回到物品页。
  • 双击顶栏：任意页面双击顶部栏，平滑回到该页顶部。
  • 列表滚动到底 / 顶即停（到边即停，无橡皮筋效果），应用已阻断浏览器把滚动传导给外层造成的"整页晃动"。
  • 物品名称过长时自动往返滚动展示，按住或手动拖动即可暂停接管（物品列表、详情页标题、仓库抽屉同款行为）。
  • 返回定位：从详情 / 编辑页返回时，上一页恢复离开时的滚动位置；点击进入新页面则从顶部开始。进入下级页面（详情、手册）后返回，出发页的功能模块 / 子项展开状态保留；切往同级或上级页面则收回展开。
  • 文本选择：长按的语义是触发交互（长按菜单、拖动查看），物品卡片、仓库卡片、按钮等控件上的文字不会触发系统文本选择；需要复制的内容不受影响——物品详情页的字段值与条码、手册正文、版本日志、扫码查询结果等仍可长按选择复制。

19. 常见问题

Q：换手机怎么迁移数据？

在旧手机导出"全部仓库 + 包含图片"的同步包或加密备份，新手机导入即可——图片本体在包里，不会出现空占位。

Q：长按文字为什么没有出现复制菜单？

长按被保留给快捷菜单。需要复制的文本请到物品详情页的字段值与条码、手册正文、版本日志等处长按选择。

Q：扫码结果商品信息查不到？

确认是联网版且查询已开启；GS1 渠道匿名额度有限，应用会依次自动转查 MXNZP 商品条码库与开源库兜底，三个来源都未收录该商品才显示无结果。MXNZP 免费档有每秒 1 次的频率限制，遇到限频响应应用会自动延时重试一次；其收录含编码中心样例数据，与官网演示工具的查询结果可能不同（以 App 内标注的来源为准）。填写 API Key 可提高 GS1 渠道额度。

Q：删除仓库会发生什么？

该仓库及其全部物品一并删除（硬删除），请先导出。删除物品为软删除。

Q：同一商品想记多个批次？

直接再扫一次同一条码并选择"新建批次"，各批次记录各自的生产日期、数量，父项卡片展开即可看到全部批次。

Q：识别文字能识别什么？

包装上的名称、规格、净含量、保质期、生产日期等印刷文字（中文模型）。识别结果的核心字段自动填入新建表单，其余进入临时字段。

Q：数据会不会被上传？

离线版没有联网代码；联网版只有在查询开关打开时才会把条码数字发送给你选择的数据源，其余数据不出设备。

Q：物品多了会卡吗？

界面按仓库隔离、列表按需渲染，几百件物品规模流畅；localStorage 容量以图片为大头（单张已压到 500KB 内）。数据量大时建议分仓库管理，并定期导出含图 ZIP 归档。

Q：误触了"清空全部数据"怎么办？

共两道确认弹窗，全部通过才会执行，执行后恢复示例数据且无法撤销——所以重要数据请养成导出习惯（加密备份最稳妥）。

Q：为什么有的物品名称在列表里会滚动？

名称超出卡片宽度时自动往返滚动展示，按住即可暂停、手动拖动查看完整名称；这是展示行为，不影响数据。

Q：识别文字拍出来是英文包装怎么办？

文字识别使用中文模型，对中文印刷体效果最好；纯英文包装可尝试识别，抽取规则主要面向中文标签（名称 / 规格 / 净含量 / 保质期 / 生产日期）。
